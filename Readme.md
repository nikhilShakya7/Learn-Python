# Learn Python 🐍

Welcome to the **Learn-Python** repository! This is a collection of mini-projects, exercises, and applications built while mastering Python. It covers a wide range of concepts—from fundamental logic and object-oriented programming (OOP) to data validation and interactive terminal games.

---

## 📂 Repository Structure

The repository contains the following independent Python projects:

### 🎮 Games & Interactive Apps
* **[Build an RPG Character](./Build%20an%20RPG%20Character)**: A Python script leveraging Object-Oriented Programming (OOP) to design and configure classic Role-Playing Game characters.
* **[Rock Paper Scissors](./Rock%20Paper%20Sissors)**: A classic interactive command-line implementation of the Rock, Paper, Scissors game.
* **[Quiz](./Quiz)**: A console-based quiz application that tests user knowledge with dynamic questions and score tracking.

### 💼 Finance & Management Utilities
* **[Budget App](./Budget%20App)**: An application designed to manage, track, and categorize personal budget expenses.
* **[Salary Tracker](./Salary%20Tracker)**: A utility tool to log, track, and analyze monthly or yearly salary distribution and history.
* **[Musical Instrument Inventory](./Musical%20Instrument%20Inventory)**: An inventory management system built to add, view, and track musical instruments.

### 🔒 Security & Data Validation
* **[Caesar Cipher](./Caesar%20Cipher)**: A simple cryptography tool to encrypt and decrypt text using the classic Caesar shift cipher technique.
* **[Medical Data Validator](./Medical%20Data%20validator)**: A project focused on data cleansing and validating structured medical records.
* **[Pin Extractor](./Pin%20Extractor)**: A utility designed to scan text inputs or files to securely identify and extract PINs/numerical codes.

### 🛠️ Core Concepts & Utilities
* **[Build a planet class](./Build%20a%20planet%20class)**: An introduction to OOP principles focusing on class structures, attributes, and methods using a planetary theme.
* **[Email Simulator](./Email%20Simulator)**: Simulates the core functionality of an email clientInbox (sending, receiving, and reading messages) in the terminal.
* **[Number-pattern-generator](./Number-pattern-generator)**: A project generating complex mathematical and visual number patterns using loops.
* **[User Configuration Manager](./User%20Configuration%20Manager)**: Handles saving, updating, and parsing user-specific settings configuration files.
